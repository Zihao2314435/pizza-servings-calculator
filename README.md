# Pizza Servings Calculator

A simple Java Swing application that calculates the number of servings based on pizza size and quantity.

## Features

- Select pizza size
- Enter number of pizzas
- Calculate total servings
- Interactive graphical user interface

## Technologies

- Java
- Java Swing
- Object-Oriented Programming

## Academic Context

This project was completed as part of Penn State's CMPSC 221 coursework.
