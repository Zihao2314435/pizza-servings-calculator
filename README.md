# Pizza Servings Calculator

A Java Swing desktop application that calculates the total number of servings based on pizza size and quantity.

## Overview

The application provides a graphical interface where users can select a pizza size, enter the number of pizzas, and calculate the estimated total servings.

Developed as part of Penn State's CMPSC 221 coursework, the project demonstrates basic GUI development, user input handling, and calculation logic in Java.

## Features

- Select pizza size
- Calculate total servings
- Interactive graphical user interface
- Display calculated results

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- Event Handling

## Academic Context

This project was completed as part of Penn State's CMPSC 221 coursework.
